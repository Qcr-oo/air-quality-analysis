# 一、项目由哪几部分组成

跑起来之前，先知道有哪几个"零件"在运转：

```
┌──────────────────────────────────────────────────────────┐
│  浏览器                                                    │
│  http://localhost:8080                                    │
└───────────────────────┬──────────────────────────────────┘
                        │ HTTP / JSON
┌───────────────────────▼──────────────────────────────────┐
│  Web 服务（Spring Boot）                                    │
│  Java 进程，监听 8080 端口                                  │
│  启动脚本：run_web.ps1                                      │
└───────────────────────┬──────────────────────────────────┘
                        │ JDBC
┌───────────────────────▼──────────────────────────────────┐
│  数据库（MySQL 8.0）                                        │
│  mysqld 进程，监听 3307 端口，库名 air_quality               │
│  启动脚本：run_mysql.ps1                                    │
└──────────────────────────────────────────────────────────┘

        以上是【运行时】需要的两个进程
─────────────────────────────────────────────────────────────
        以下是【数据准备】时用的，日常运行不需要
┌──────────────────────────────────────────────────────────┐
│  Python 脚本（src/step1~step9）                            │
│  读取原始 CSV → 清洗 → 分析 → 建模 → 写进 MySQL              │
└──────────────────────────────────────────────────────────┘
```

**关键理解**：

| 问题 | 答案 |
|---|---|
| 日常要用几个进程？ | **2 个**（mysqld + java） |
| 需要跑 Python 吗？ | **不需要**，数据已经在数据库里了 |
| Python 脚本什么时候用？ | 只在**重建数据**时用（比如原始数据变了） |

# 二、日常启动（最常用）

## 步骤 1：启动数据库

**新开一个 PowerShell 窗口**，执行：

```powershell
powershell -ExecutionPolicy Bypass -File F:\myprogect\.tools\run_mysql.ps1
```

**预期输出**：

```
[2/2] Starting mysqld on 127.0.0.1:3307
      data dir : F:\myprogect\.tools\mysql-data
      user     : root / 123456
      stop with: Ctrl+C   (or close this window)
```

> ⚠️ **这个窗口要一直开着**，关掉数据库就停了。
>
> 📌 **不需要管理员权限。** 这是项目自带的独立 MySQL 实例，
> 跟系统里那个要管理员才能启动的服务（端口 3306）互不干扰。

**验证数据库起来了**（可以在另一个窗口跑）：

```powershell
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -h 127.0.0.1 -P 3307 -u root -p123456 --protocol=TCP -e "SELECT VERSION(); SELECT COUNT(*) AS cities FROM air_quality.dim_city;"
```

应该返回 `8.0.45` 和 `319`。

## 停止服务

在对应窗口按 **Ctrl + C**，或者直接关掉窗口。

**如果窗口找不到了**（比如重启过终端）：

```powershell
# 强制停掉两个进程
Get-Process mysqld,java -ErrorAction SilentlyContinue | Stop-Process -Force
```

> MySQL 建议优雅关闭（避免数据损坏），但日常开发直接杀进程也能接受，
> 因为数据库内容是脚本生成的，随时可以重建。

# 三、验证服务是否正常

不确定状态时，跑这几条：

```powershell
# 1. 两个端口是否在监听
Get-NetTCPConnection -LocalPort 3307,8080 -State Listen |
  Select-Object LocalPort, OwningProcess

# 2. 数据库是否可查
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -h 127.0.0.1 -P 3307 `
  -u root -p123456 --protocol=TCP -e "SELECT COUNT(*) FROM air_quality.dim_city;"

# 3. 接口是否正常
Invoke-RestMethod http://localhost:8080/api/overview | ConvertTo-Json -Depth 4
```

**接口正常时应返回**：

```json

  "msg": "success",

    "fiveYearChange": -13.3,

  }
```

# 五、如果想重跑数据（可选）

> **日常不需要。** 只有原始数据变了、或者你想重新生成结果时才用。

## 前提

| 组件 | 位置 | 说明 |
|---|---|---|
| Python 3.14 | `C:\Users\瞿崇荣\AppData\Local\Programs\Python\Python314` | 已装 pandas / numpy / matplotlib / scikit-learn / pyspark / pymysql |
| 便携版 JDK 17 | `F:\myprogect\.tools\jdk17` | Spark 用，脚本会自动找 |

## 分阶段跑

```powershell

```

### 第一阶段：单机处理（约 3 分钟）

```powershell

python step4_analyze.py           # 时空分析   约 20 秒（出 5 张图）
python step5_model.py             # 机器学习   约 2 分钟
```

### 第二阶段：Spark 全量（约 4 分钟）

```powershell
python step6_spark.py             # 全量清洗聚合   约 3 分钟
python step9_fullscale_figures.py # 生成论文用图   约 20 秒
```

### 第三阶段：入库（约 1 分钟）

```powershell
# 先确保 MySQL 已启动（run_mysql.ps1）

```

### 可选：Spark MLlib 建模（约 25 分钟）


> ⏱ **这个要 25 分钟**，因为 MLlib 的 GBT 是逐棵树串行训练的。
> 日常演示**不需要跑**。

# 六、故障排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 浏览器打不开 `localhost:8080` | Web 服务没启动 | 跑 `run_web.ps1` |
| 页面显示"加载失败" | MySQL 没启动，或数据没导 | 先跑 `run_mysql.ps1`，再 `python step7_mysql.py` |
| 端口被占用启动失败 | 上次的进程没关干净 | `Get-Process mysqld,java \| Stop-Process -Force` |
| 页面能开但图表全空 | 数据库表是空的 | `python step7_mysql.py` |
| `Could not connect to MySQL` | 端口不对（用了 3306 而不是 3307） | 检查 `application.yml` 里的 url |
| `Access denied for user 'root'` | 密码不对 | 本项目密码是 `123456` |
| `run_web.ps1` 卡在 Maven 下载 | 首次下载依赖 | 耐心等，用的是阿里云镜像 |
| `python step*.py` 报找不到模块 | 不在 `src` 目录下 | `cd F:\myprogect\01-毕业设计\07-系统实现\src` |
| `step6_spark.py` 报 Java 相关错误 | 便携版 JDK 被删了 | 重新下载 Temurin JDK 17 解压到 `.tools\jdk17\` |
| `git push` 报 `Failed to connect port 443` | GitHub 网络波动 | **等几秒重试**，别改配置 |
