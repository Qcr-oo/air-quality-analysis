 三、划分训练集与测试集
======================================================================

  【方法论点：时序数据不能随机划分！】
    随机划分会把 2018 年的数据混进训练集，让模型"见过未来"，
    测试分数虚高，上线就崩 —— 这叫数据泄漏。

    正确做法：按时间切 —— 2017 年训练，2018 年考试。
    这才是真实场景：用历史预测未来。

  训练集（2017 年）：270,227 行
  测试集（2018 年）：266,094 行

 四、先澄清一件事：「换算」不是「预测」
======================================================================

  AQI 是怎么来的？—— 六项污染物各算一个分指数 IAQI，取【最大值】。
  也就是说 AQI = f(PM25, PM10, SO2, NO2, CO, O3)，是一个确定性函数。

  拿「当前污染物」预测「当前 AQI」，本质是把这个函数拟合一遍，
  这叫【换算 / 单位转换】，不是预测 —— 因为真实场景里，
  你要预测的那个时刻，污染物浓度本来就还不知道。

  下面把它算出来，只是作为参照，看看这个函数被拟合得多准。

  换算任务（用当前污染物算当前 AQI）：
    R2 = 0.6615   MAE = 14.20   RMSE = 25.00

  【为什么没到 0.99？】
    因为 O3_8h（臭氧 8 小时滑动均值）缺失 31.5%，
    而臭氧恰恰是夏季 AQI 的首要污染物，缺了它自然拟合不全。
    另外 AQI 取 max 是分段线性函数，存在折点，树模型需要足够深度才能逼近。

 五、预测任务 A：提前 1 小时预测 AQI
======================================================================

  【必须引入「持续性基线」】
    "什么都不算，直接拿上一小时的 AQI 当作预测值" —— 这叫持续性基线
    （persistence baseline）。空气质量自相关性极强，这个朴素基线往往很能打。
    如果花大力气训的模型赢不了它，模型就没有存在价值。
    所有时间序列预测论文都必须报这个基线。

  【提前 1 小时】预测 AQI(t+1)
    持续性基线（当前值当预测）                  R2=0.9818  MAE=  2.12  RMSE=  5.80
    GBDT 模型                        R2=0.9849  MAE=  1.72  RMSE=  5.27   (训练+预测 5.1s)
    -> 相比基线 MAE 降低 18.8%
       [OK] 模型优于基线，说明除自相关外还学到了额外信息

  【提前 24 小时】预测 AQI(t+24)
    持续性基线（当前值当预测）                  R2=0.3534  MAE= 20.19  RMSE= 34.35
    GBDT 模型                        R2=0.5591  MAE= 17.03  RMSE= 28.36   (训练+预测 8.0s)
    -> 相比基线 MAE 降低 15.6%
       [OK] 模型优于基线，说明除自相关外还学到了额外信息

 六、预测任务 B：提前 24 小时污染预警
======================================================================

  业务问题：明天这个时刻会不会出现污染？
  定义：AQI > 100 为「污染」（轻度污染及以上）。

  训练集：51,521 条污染 / 218,706 条良好
  测试集：42,321 条污染 / 223,773 条良好

  基线（沿用当前状态，不做任何预测）：
    准确率 0.8716

  GBDT 分类器：
    准确率 Accuracy = 0.8888
    AUC            = 0.9153
    用时 12.2 秒

  分类报告：
                  precision    recall  f1-score   support
    
    良好(AQI<=100)     0.9203    0.9501    0.9350    223773
     污染(AQI>100)     0.6816    0.5649    0.6178     42321
    
        accuracy                         0.8888    266094
       macro avg     0.8009    0.7575    0.7764    266094
    weighted avg     0.8823    0.8888    0.8845    266094
    
  混淆矩阵：
                    预测良好     预测污染
    实际良好         212,606     11,167
    实际污染          18,415     23,906

  【怎么解读】
    漏报（实际污染、预测良好）= 18,415 条。预警系统里，漏报的代价通常高于误报，
    所以实际业务中会把判定阈值调低（宁可多报），用准确率换召回率。
    这个权衡叫作 precision-recall trade-off。

 七、特征重要性分析
======================================================================

  置换重要性（permutation importance）：把某一列的值随机打乱，
  看模型性能掉多少。掉得越多，说明这列越重要。

  [!] 注意：此处 n_jobs=1（单进程）。
      因为 joblib 的并行后端要把临时目录路径编码成 ASCII，
      而本机用户目录是中文（C:\Users\瞿崇荣\...），并行会直接崩溃。
      这是中文 Windows 上跑 Python 的经典坑。

  计算用时 4 秒

  置换重要性排名（t+24 模型，仅列正值）：
    PM25_lag1          0.220  ########################################
    aqi_now            0.137  ########################
    O3_lag1            0.049  ########
    lat                0.037  ######
    PM10_lag1          0.037  ######
    month              0.028  #####
    NO2_lag1           0.023  ####
    hour               0.008  #
    lon                0.007  #
    is_heating         0.005  #
    aqi_lag1           0.002  #
    aqi_roll24_std     0.001  #

  【业务解读】
    如果 aqi_lag24（昨天同一时刻）排第一，说明污染的「日周期」很强 ——
    昨天这个点脏，今天这个点大概率也脏。
    如果 hour / month / is_heating 也有贡献，说明模型学到了
    日内节律和季节规律，这些是超越单纯自相关的「额外信息」。

 八、城市污染类型聚类（K-Means）
======================================================================

  目标：把城市按「污染特征」分成几类，识别不同污染类型。
  特征：平均 AQI、六项污染物均值、PM10/PM25 比值、沙尘率、采暖效应

  参与聚类：319 个城市

  【为什么必须先标准化？】
    K-Means 用欧氏距离衡量相似度。PM10 的数值在 0–2000，沙尘率在 0–1。
    不标准化的话，沙尘率的影响会被完全淹没。
    标准化后每列均值 0、标准差 1，各特征权重才可比。

  选择聚类数 k（轮廓系数越大越好）：
    k=2   轮廓系数 = 0.3111
    k=3   轮廓系数 = 0.2027
    k=4   轮廓系数 = 0.2209
    k=5   轮廓系数 = 0.2312
    k=6   轮廓系数 = 0.2074
    k=7   轮廓系数 = 0.1935
  -> 最优 k = 2（轮廓系数 0.3111）

  各聚类特征画像：
        城市数  平均AQI  PM25   PM10   SO2   NO2   CO    O3  PM10_PM25比  沙尘率  采暖效应
    类型                                                                       
    0   209   61.9  37.6   65.6  16.5  25.8  0.9  58.5         1.8  0.0  17.7
    1   110   95.8  62.7  116.6  31.4  39.2  1.3  60.4         1.9  0.1  39.4

  【怎么读这些聚类】
    注意：各污染物的【绝对浓度】彼此高度相关（一个城市 PM25 高，
    PM10 基本也高），所以 K-Means 首先按「污染水平」把城市分开，
    而不是按「污染类型」。k=2 的轮廓系数最高，正是这个原因。

    要区分【污染类型】，必须看【比值】这类构成指标。
    所以下面分两步：先用聚类看水平，再用比值显式判类型。

  各聚类画像（附典型城市 = AQI 最接近该类中位数的城市）：

    类型 0：209 个城市
      平均 AQI 61.9    PM10/PM25 1.79    沙尘率 2.6%
      判定：相对清洁 · 沙尘影响小
      典型城市：河池市、鄂尔多斯市、衢州市、乌兰察布市、上饶市
      该类型中污染最重：北京市、淮南市、吴忠市

    类型 1：110 个城市
      平均 AQI 95.8    PM10/PM25 1.87    沙尘率 6.6%
      判定：污染较重 · 沙尘影响明显
      典型城市：自贡市、石嘴山市、天津市、长治市、渭南市
      该类型中污染最重：和田地区、喀什地区、阿克苏地区

  【显式分型：用比值区分沙尘型与燃烧型】

    判据来自前面的分析（第 4 步 Step4 已经验证过）：
      沙尘天 PM10/PM25 比值 2.4  vs  非沙尘天 1.7
    沙尘主要是粗颗粒物（PM10），燃烧排放主要是细颗粒物（PM2.5）。
    所以比值越高，越偏沙尘型。

    分型阈值：PM10/PM25 比值 > 2.00 且 沙尘率 > 4% -> 沙尘型
              平均 AQI > 84.6 且非沙尘型 -> 燃烧型

    沙尘型     43 城   AQI 均值  81.3   PM10/PM25 2.45   沙尘率 12.2%
           代表：和田地区、喀什地区、阿克苏地区、吐鲁番地区、阳泉市、酒泉市
    燃烧型     69 城   AQI 均值 100.5   PM10/PM25 1.72   沙尘率  4.5%
           代表：衡水市、邢台市、保定市、石家庄市、邯郸市、德州市
    一般型    109 城   AQI 均值  73.7   PM10/PM25 1.67   沙尘率  3.0%
           代表：日照市、常州市、鄂州市、马鞍山市、信阳市、镇江市
    清洁型     98 城   AQI 均值  51.1   PM10/PM25 1.76   沙尘率  1.1%
           代表：衢州市、河池市、乌兰察布市、上饶市、温州市、湘西州

  【结论】
    沙尘型城市集中在西北（新疆、甘肃、宁夏、内蒙古），
    污染的主要来源是自然扬尘；
    燃烧型城市集中在华北平原（河北、河南、山东），
    污染来自钢铁、水泥、燃煤与机动车。

    两类城市的治理思路完全不同：前者靠生态防护林与沙源治理，
    后者靠产业结构调整与排放管控。
    —— 这正是「城市污染分型」的现实意义。

  方法论要点（答辩与面试必问）
    1. 「换算」不等于「预测」，AQI 是污染物的函数，别拿它当预测成绩
    2. 时序数据必须按时间切分，随机切分会造成数据泄漏
    3. 必须引入持续性基线，赢不了基线的模型没有价值
    4. 滞后特征只能来自过去，shift 之后才能 rolling
    5. K-Means 前必须标准化，否则量纲大的特征主导距离
    6. 中文 Windows 上 joblib 并行会因路径编码崩溃，需 n_jobs=1
